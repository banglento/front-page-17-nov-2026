A front-page newspaper poster summing up Tuesday 17 November 2026's world news in one image: the Kerch Bridge struck again, mines in the Strait of Hormuz, the first Xi–Trump–Putin trilateral confirmed, the US losing measles elimination status, the Pentagon failing its audit for a ninth year, and the day's briefs from Japan, Europe and the Middle East. The poster is drawn procedurally at grade time by `main.py` — standard library only, no network, no image assets.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`, a 1024×1024 PNG.
